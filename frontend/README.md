# PickleStack Frontend (`frontend/`)

React 19 + Vite 8 + Tailwind CSS v4 application for the **Naga City Pickleball Association (NCPA)**.

See the root [README.md](../README.md) for architecture, roles, and feature overview, and [DESIGN_HANDOFF.md](../DESIGN_HANDOFF.md) for design tokens, component specs, and prototype parity notes.

## Scripts

```bash
npm install      # Install dependencies
npm run dev      # Start Vite dev server
npm run lint     # Run oxlint across src/
npm run build    # Production build to dist/
npm run preview  # Serve built dist/ locally
```
